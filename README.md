# Streamflix

Netflix-inspired movie and TV discovery app built with Next.js, React, Tailwind CSS and TMDB.

## Setup
1. Copy .env.example to .env.local.
2. Add your TMDB API Read Access Token as TMDB_API_READ_ACCESS_TOKEN.
3. Run npm install and npm run dev.

Streamflix uses TMDB for metadata and images and does not host copyrighted video files.
