# Roku Channel Store app

Roku requires a native BrightScript + SceneGraph channel. It cannot install a Tizen, webOS or Android package.

Implementation requirements:
- SceneGraph browse rows and detail screens with Roku remote focus.
- Secure calls to the existing Streamivio catalogue/API.
- Roku-supported video playback and adaptive streaming.
- Account linking that does not require typing a long password with the remote.
- Store metadata, channel artwork, privacy and content-rights documentation.

This is a separate native implementation phase; do not submit a website wrapper as a Roku channel.
